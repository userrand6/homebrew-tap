# Userrand6 Tap

## How do I install these formulae?

`brew install userrand6/tap/<formula>`

Or `brew tap userrand6/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "userrand6/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
